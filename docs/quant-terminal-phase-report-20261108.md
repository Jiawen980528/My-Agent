## 已完成

### 行情数据

- TickFlow 报价和分钟数据统一返回 `source`、`market_time`、`received_at`、`age_seconds`、`stale`。
- 批量分钟接口按标的返回新鲜度状态。
- 成交额全天预测只使用真实分钟 `amount` 和历史同期交易日样本；少于 3 个可比交易日时返回不可用。
- 资金流仍明确标记为东方财富来源，不把普通成交量推导成主力资金。

### 交易流水与复盘

- 支持任意证券、任意交易日的成交流水。
- 成交 CSV 包含交易 ID、证券、时间、方向、数量、价格、费用和来源，并按交易 ID 幂等更新。
- 保留 2026-11-06 两只 ETF 的历史兼容数据。
- 事后理论最优、实际成交和不交易对照在界面上分开显示。

### 决策辅助

- 缺少行情、板块、市场量能或账户信息时 fail-closed 为等待。
- 手工/CSV/未核验账户不会触发条件加仓建议。
- 输出触发价、失效价、建议数量、最大风险金额、生成时间和有效期。
- 第一阶段不包含自动下单。

### 看盘界面

- 持仓看盘支持桌面拖拽/缩放、右键显示控制、标的与板块添加、持仓/网格/横条布局。
- 移动端降级为纵向布局。
- 持仓终端布局、关联板块、额外标的、显示面板和栏宽保存到后端用户偏好，并保留 localStorage 缓存。
- 页面显示行情来源、更新时间和过期/连接状态。
