- 移动端固定底部导航已加入独立“量化”入口，桌面侧栏同步显示；路由为 `/quant/myagent-quant`，不改变原有看板和登录流程。
- 移动端看板编辑态已支持组件上移、下移和移除；桌面端继续使用自由拖拽与八向缩放，手机端不抢占图表触摸滚动手势。
- 上证指数分时已改为动态观察区间：白线为真实指数（权重口径），黄色为 TickFlow 全市场真实快照等权参考（题材/等权线）；没有覆盖时明确显示不可用，不用成交额或普通均价伪造。
- 指数分时悬浮明细会跟随第二条线的真实名称显示，不再把题材/等权参考误标为普通“均价”。
- 持仓推演提醒的刷新提示已与实际查询周期对齐为 30 秒，避免把 30 秒轮询误显示为 15 秒。
- 指数没有真实领先/等权序列时不再绘制空黄色线或显示“均价线”图例；缺失状态明确提示，避免把空序列误当成第二根有效曲线。
- 指数/ETF 分时图在滚轮或底部滑块缩放后，会按当前可视区间重新计算自适应纵轴；不会继续被全天异常点或远端数据压扁，并有组件回归测试覆盖。
- 指数分时组件回归已明确验证：权重线使用白色，真实领先/等权参考线使用黄色；没有第二条真实序列时不绘制空黄线、不显示“均价”误导信息。
- 关联板块搜索已修复前端二次过滤问题；复合中文关键词（如“半导体设备材料”）会保留后端返回的“半导体设备/半导体材料”匹配项。
- 关联板块选择现在同时持久化代码和名称；不在前端首批目录中的远程搜索结果不会再被清空，板块名称会继续传给 TickFlow 等权分钟聚合，避免无故回退东方财富公开行情。
- 量化服务同时提供 `/health` 与 `/api/health` JSON 探活别名，避免 `/quant/api/health` 被静态 SPA 回退误判为健康。

## 部分完成或依赖外部条件

- TickFlow 实时、分钟、日线能力已接入路由，但实际可用能力取决于当前账户套餐、API Key 和交易时段。
- 板块行情与资金流按来源标注；没有真实返回时保持不可用，尚未能保证所有用户自定义板块都有完整历史与实时数据。
- AI 分析入口和规则决策已存在；AI 供应商若返回 401/限流，需要在供应商侧配置访问权限，代码不能绕过。
- 推荐快照、模拟盘和复盘统计已保留，但成功率样本不足时不能得出稳定结论；模拟盘的长期归因仍需更多真实模拟成交样本。
- 外围市场新闻和情绪影响有展示入口，新闻原文归因和长周期情绪建模仍需继续完善。
