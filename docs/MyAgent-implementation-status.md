# MyAgent 当前实现状态

更新时间：2026-11-26

这份清单用于区分“已完成的代码与测试”和“仍需真实数据权限或继续开发的部分”。它不代表系统已经完成全部交接需求。

## 已完成并验证

- 主侧栏收敛为：看板、我的持仓、持仓推演、个股研究、市场环境。
- 模拟盘、预测复盘、提醒规则保留路由，并收纳到“我的持仓”页内的二级入口；没有连接券商或真实下单。
- 持仓工作区默认只展示后端已记录的个人持仓；临时监控标的只在“全部监控”中显示。
- 已记录但来源/数量未核实的持仓仍保留，并明确显示“持仓未核实”。
- 持仓列表、顶部计数和持仓标签使用统一的 `holding_source` 口径。
- 持仓工作区、板块搜索、关联板块和多周期曲线的目标组件测试通过。
- 最近一次精简侧栏后的核心回归：4 个测试文件、18 个测试全部通过（导航、扩展路由、实时行情开关和持仓工作区）。
- 暗黑模拟盘独立页面已核实包含：虚拟现金/总资产/持仓市值、实时或定版估值、订单、成交、净值曲线、回合明细、胜率、盈亏比和最大回撤；该页面只调用 `/api/paper/*` 模拟账户接口，不连接券商。
- 后端针对持仓桥接、板块资金、预测来源、决策引擎、模拟盘和监控的回归：77 个测试全部通过（仅有 pytest 依赖的弃用警告）。
- 前端构建通过；线上量化容器和原 MyAgent 容器均正常运行。
- 推荐快照复盘后端测试 `test_recommendation_snapshots.py`：1/1 通过。
- 数据缺失时前端显示不可用/等待，不使用普通 K 线伪造资金流或板块曲线。

## 部分完成或依赖外部条件

- TickFlow 实时、分钟、日线能力已接入路由，但实际可用能力取决于当前账户套餐、API Key 和交易时段。
- 板块行情与资金流按来源标注；没有真实返回时保持不可用，尚未能保证所有用户自定义板块都有完整历史与实时数据。
- AI 分析入口和规则决策已存在；AI 供应商若返回 401/限流，需要在供应商侧配置访问权限，代码不能绕过。
- 推荐快照、模拟盘和复盘统计已保留，但成功率样本不足时不能得出稳定结论；模拟盘的长期归因仍需更多真实模拟成交样本。
- 外围市场新闻和情绪影响有展示入口，新闻原文归因和长周期情绪建模仍需继续完善。

## 尚未宣称完成

- 全部前端测试套件尚未全绿；最近一次全量回归为 103 个测试文件中 94 个通过、9 个失败，687 个测试中 634 个通过、53 个失败。之后已修正 AI 助手流式测试的模式前置条件，相关目标测试现为 3/3 通过；其余历史策略设置、因子生成、资源导入等失败仍需逐项隔离处理。
- 外部通知实际发送链路尚未完成端到端验证。
- 不同数据源在所有交易时段的持续稳定性、限流恢复和断线重连仍需运行期观察。
- 未执行任何真实交易，也未读取或修改券商账户数据。
